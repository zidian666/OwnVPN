# OwnVPN

源码从 0.3.9 起使用 Git 管理，提交和发布标签约定见 [版本管理](docs/version-control.md)。

Windows 11 / x64 原生 C++ 桌面客户端。加载公司 `.ovpn`，使用用户名、密码和 6 位动态验证码连接公司内网。采用本机官方 OpenVPN 2.x 核心的管理接口，不依赖 OpenVPN GUI 的窗口自动化。0.2 版新增本机 TOTP 生成和二维码导入。

0.2.5 使用绿色底、白色字母 O 的应用图标，嵌入 16–256 像素多尺寸图标，同步用于程序文件、窗口、任务栏和主界面标识。矢量源文件为 `resources/app-icon.svg`，开发时可用 `tools/generate_app_icon.py`（Pillow）重新生成 ICO；运行程序无需 Python。

## 使用

0.3.9 将顶部连接状态文字从 14 磅增大到 18 磅，并与左侧图标垂直居中对齐；右侧可复制 IP 同步对齐，状态说明下移，避免遮挡。

0.3.8 修复点击 VPN IP 后焦点框覆盖数字的问题。IP 不再绘制矩形焦点框，键盘切换到 IP 时用文字下方的细线提示焦点；其他按钮尊重系统的焦点提示状态。

0.3.7 去掉界面中的点状分隔符和进度省略号，保留 IP 与数值本身的小数点。连接成功后只在“已连接”右侧显示 VPN IP，点击可复制，断开后隐藏；移除原来的“VPN 地址 / 仅公司路由走 VPN”说明。“复制即时密码”和“尝试绕过DNS”提供鼠标悬停说明。自动重连与尝试绕过DNS在没有保存偏好时默认勾选，手动选择按配置保留；自动重连仍需启用自动验证码。下载、上传累计流量分别按大小显示 KB 或 MB。

0.3.6 内置 2026-11-11 核实的首次解析值：`ksvpn.knownsec.com → 106.39.24.170`，`vpn.knownsec.com → 123.125.242.132`。首次遇到对应域名且该配置没有历史 IPv4 地址时初始化缓存，已有缓存优先；系统 DNS 解析成功后更新 IP，永久保存。初始化和回退均写入诊断。仍需勾选“尝试绕过DNS”，且 DNS 解析失败，才会尝试缓存 IP。

0.3.5 在展开的“使用说明”中新增第 6 条：首次使用公司wifi连接vpn时，如果出现DNS解析失败，可使用其它网络连接vpn，成功连接后可以切换至公司wifi，以后可以使用公司wifi直接连接。（来自公司网络限制）如需在DNS解析失败时使用已保存的IP，请勾选“尝试绕过DNS”。历史 IP 改为永久保留，不再按天数过期；每次 DNS 解析成功都会更新对应域名、地址族的缓存 IP 和解析时间。

0.3.4 在“自动重连”右侧新增“尝试绕过DNS”，默认勾选，按配置记忆。每次连接先通过当前系统 DNS 解析配置中的服务器域名；解析成功时保存历史 IP，继续按原域名连接。只有解析失败且已勾选时，才用同一配置、同一域名及匹配 IPv4/IPv6 协议的历史 IP 尝试连接。历史地址永久保留；0.3.6 起提供内置初始值，运行时不查询公共 DNS；没有有效缓存时仍按原配置连接。临时生效配置只替换服务器地址，保留端口、协议和所有证书验证，隧道结束后删除。DNS 查询在后台执行，支持取消。

普通连接的最近 150 条脱敏诊断保存到 `%LOCALAPPDATA%\OwnVPN\connection-diagnostic.log`，包含 DNS 成功/失败、缓存 IP、缓存天数、开关状态及连接结果，不记录密码、验证码、二维码密钥或证书内容。DNS 缓存位于对应配置的私有目录 `dns-cache.txt`。

0.3.3 合并原来的“绑定设置”和“自动生成”：验证码输入框右侧显示勾选框和“自动生成”按钮。勾选框控制自动生成的启停，点击按钮打开验证码绑定窗口；未绑定时勾选也会引导绑定。键盘可用 Tab 切换两项，空格切换勾选状态，Enter 或空格打开绑定窗口。

0.3.2 在“显示密码”右侧新增可点击文本“复制即时密码”。点击后复制“密码＋当前 6 位验证码”，无分隔符；自动生成模式会先刷新当前验证码，手动模式使用填写的验证码，保留前导零。复制成功后短暂显示“已复制”；密码或验证码不完整时点击会提示补全。

0.3.1 修复主窗口隐藏或最小化后，托盘右键菜单被托盘面板遮挡的问题。菜单采用独立的置顶工具窗口承载，打开时取得前台焦点，关闭后隐藏；不会恢复主界面，也不会将主界面设为置顶。菜单位置避让托盘图标，连接、断开和退出行为保持一致。

0.3.0 将主界面调整为 500 × 588 的紧凑布局（随屏幕 DPI 缩放）：顶部显示连接状态，表单保留配置、用户名、密码和动态验证码；复制及绑定按钮位于对应字段旁，诊断和使用说明在底部展开。

0.2.9 新增系统托盘：点击窗口右上角叉号或最小化按钮，将窗口收起到托盘，当前 VPN 和自动重连继续运行。点击托盘图标可恢复窗口，右键可“显示主界面”“连接 VPN / 断开连接 / 取消自动重连”“退出”。只有选择托盘“退出”才停止重连、正常断开 VPN 并结束本次授权服务。未连接时 O 为白色，收到真实连接成功状态后 O 变为金黄色，窗口和托盘图标同步；断线后恢复白色。

0.2.8 修复在不同缩放比例的显示器之间拖动后，标题/背景保留旧比例、标签残影及控件错位的问题。DPI 切换统一更新字体、目标屏幕布局和整窗/子控件重绘；使用说明滚动区及验证码设置窗口也支持跨屏 DPI 更新。

0.2.7 在窗口底部新增“使用说明”，默认收起。点击后展开邮件附件下载、配置导入、获取并导入二维码、自动重连及连接的五步说明；其中二维码门户链接可点击，在默认浏览器打开。再次点击可收起；说明和诊断切换显示，空间不足时支持滚动。

1. 本机需已安装官方 OpenVPN Community（含虚拟网卡驱动）。本机检查到版本 2.7.8，路径为 `C:\Program Files\OpenVPN\bin\openvpn.exe`。
2. 双击 `dist` 中带版本号的程序（如 `OwnVPN-0.3.6.exe`），选择已有配置，或点击“导入配置”选择 `.ovpn`。
3. 配置所需的 `.crt`、`.key` 应位于配置指定的相对路径。遇到缺失的 `users.pem` 时，程序会提示单独选择它。
4. 填写用户名、密码、6 位验证码。实际提交内容为 **密码后直接拼接验证码**；验证码的前导零会保留。
5. 密码可选记住，右侧“显示密码”可临时显示/隐藏输入，默认隐藏。验证码不再记住，也不写入凭据存储；升级时清理旧版保存的手动验证码。“清除已记住的登录信息”清除当前配置的用户名、密码。
6. 点击连接后，仅后台连接服务请求 Windows UAC 管理员授权。0.2.4 在同一次程序运行期间保留这份授权，断开后再连或切换配置重连均复用同一后台服务。关闭程序后服务退出，下次启动首次连接重新授权；后台服务异常退出也需要重新授权。拒绝授权不会发起 VPN 连接。只有收到 OpenVPN 的 `CONNECTED,SUCCESS` 才显示已连接。
7. 点击“断开连接”仅结束本次隧道，已授权服务保持空闲。窗口叉号收起到托盘；通过托盘“退出”才请求 OpenVPN 正常退出、清理网卡和路由并结束授权服务。
8. 0.2.3 的诊断保留最近 150 条记录，重试不会清空上一轮；显示毫秒时间和本轮累计耗时，并区分服务接入、核心创建、管理接口握手、认证和路由配置。连接服务接入后迟迟不报告启动进度，也会超时结束。

本机重连诊断可显式运行 `OwnVPN.exe --diagnose-connect <已导入配置的32位ID>`。它只尝试一次，需要该配置已保存用户名、密码并启用自动验证码，仍使用正常的 UAC 授权。成功后窗口和连接保持运行；脱敏诊断写入 `%LOCALAPPDATA%\OwnVPN\reconnect-diagnostic.log`，不包含密码、验证码、绑定密钥或 VPN 地址。普通启动不写该日志。

0.2.6 修复管理接口认证后可能停留在等待启动的问题：认证成功后主动安排状态订阅、`hold off`、`hold release`，不再依赖单次异步 HOLD 通知。所有管理命令逐条确认应答后发送下一条，包括用户名和密码命令；验证码如在等待中失效，禁止继续发送。记录放行应答，命令应答等待上限 10 秒，放行后未进入认证/网络阶段上限 15 秒。启动顺序和命令队列分别由独立模块管理。

`--diagnose-reconnect <配置ID>` 用于一次受控实测：启用自动重连，首次连接成功两秒后模拟一次断线，自动连回并保持连接；遇到连接失败则停止诊断重试。测试会短暂断开 VPN。开发时 `build/ownvpn_tests.exe --probe-startup` 可使用已导入的 CA 文件，在仅指向环回地址的配置上验证放行及合成测试凭据的命令确认，不使用公司账号、密码或验证码，也不创建网卡/路由。`--probe-startup-repeat` 在同一进程连续验证 8 轮；原有 `--probe` 仍不释放 HOLD。

## 复制和自动重连（0.2.4）

- 密码框、验证码框右侧均有复制图标。点击复制完整内容，成功后显示勾号；密码无需先显示明文。空内容不可复制。自动验证码仍为只读，点击复制时先刷新到当前周期。
- 绑定并启用“自动生成”后，可勾选“自动重连”。该选项默认勾选，手动选择按配置保存。OpenVPN 报告意外断线或本次隧道异常退出后，等待 3、6、12、24、30 秒逐步重试，最多间隔 30 秒。连接稳定一分钟后恢复最初等待时间。
- 每次重连重新取有效验证码，不重复使用已经取用的验证码；必要时等待下一验证码周期。密码仅在当前程序内保留用于重连，“记住密码”未勾选时仍不写入凭据存储。
- 手动断开、取消重连、托盘退出程序，或服务器拒绝认证/验证码不可用时停止自动重试。窗口叉号隐藏后继续重连。授权服务退出时自动重连暂停，需手动连接重新授权。
- 已连接并勾选“自动重连”后，“测试自动重连”可用。点击注入与实际断线相同的连接中断事件，正常清理当前隧道，再按上述策略自动连回；测试会短暂中断正在使用的 VPN。测试不会更改系统网卡、服务器或原始配置。

## 自动验证码（0.2）

1. 先选择 VPN 配置并填写 VPN 用户名，点击“绑定设置”。
2. 导入公司提供的原始绑定二维码图片（PNG/JPEG/BMP），或输入 Base32 绑定密钥 / `otpauth://totp/…` 链接。二维码只在本机由 Windows WIC 和 ZXing-C++ 解码，不会上传，不会复制原图。
3. 算法支持 SHA1、SHA256、SHA512；周期支持 10–300 秒，默认 30 秒。链接/二维码里的参数优先。当前 VPN 只接受 6 位，8 位绑定会明确拒绝。
4. 点击“保存绑定”后启用“自动生成”。密钥按 **VPN 配置 + 精确用户名** 隔离，保存在 Windows 凭据管理器中。设置文件、日志和连接参数不包含绑定密钥。
5. 自动模式下，验证码框显示当前 6 位数字并按绑定周期实时更新，下面显示剩余有效时间。框为只读，可复制。预览不会占用或消耗验证码；登录时仍在认证请求到达后由连接进程取码，避免 UAC 等待使验证码过期。距过期不足 5 秒时等待下一周期；同一账号上次已经取用的周期也会等待更新，以避免短时间重连重复用码。
6. 取消“自动生成”可切回手动输入，本次窗口内的手动输入可暂时保留，退出后不保存。设置中的“删除绑定”单独删除当前配置、当前用户名的本机密钥；不改动手机上的账号。“清除已记住的登录信息”不删除 TOTP 绑定。
7. 若与手机码不一致，在“绑定设置”中输入手机当前验证码，点击“核对算法和周期”。程序仅在本机使用已有密钥匹配 SHA1/SHA256/SHA512、30/60 秒及所选周期的前后一个时间窗口。换下一轮手机验证码后再次核对；两轮一致才填入候选参数，仍需点击“保存绑定”生效。重复输入同一轮码不算第二轮，核对数据不保存、不发送到公司服务器。
8. 已绑定时密钥框可以留空；所选算法和周期会与现有密钥一起保存，已修复旧版忽略这类参数修改的问题。若只重新保存相同参数，不重置使用周期保护。

必须具备与公司服务器已登记的一致绑定密钥。Microsoft Authenticator 支持 TOTP，但不是它的所有注册二维码都是 `otpauth`：微软推送通知/设备激活链接、HOTP 及普通网页二维码不支持。没有原始绑定资料时，自动模块可安装和测试，但无法凭现有 6 位码或 VPN 证书恢复密钥。

本机和手机时间必须准确。程序使用 UTC 时间计数，不自动修改系统时间、不联网校时。参数匹配只用于排查，不能从验证码恢复密钥；两端必须使用同一份仍有效的绑定密钥。未进行真实公司账号端到端验证。

## 分流与配置兼容

- 保留配置和服务器下发的公司路由；过滤接管 IPv4/IPv6 默认路由的常见指令。普通互联网流量继续使用本地默认路由。
- 不猜测公司内网网段，也不自动新增全网代理；能否访问某个内网网段取决于公司下发的路由与授权。上线验证应核对 Windows 路由表及真实内网服务。
- 导入到 `%LOCALAPPDATA%\OwnVPN\profiles` 的独立私有副本；源附件不修改。
- 旧 `ns-cert-type server` 转为 `remote-cert-tls server`。保留证书验证，不降低 TLS 安全级别或自动启用过时算法。
- 首版支持常见客户端参数、外部/内嵌证书密钥。脚本、插件、嵌套配置、任意管理接口、自定义日志路径、连接块及未支持参数会报错，便于显式扩展。
- 首版不支持加密私钥的额外口令、代理口令、交互式 CRV1 二次挑战。当前公司配置不要求这些。失败不自动反复提交同一验证码；重连需要手动更新验证码。

## 构建与测试

```powershell
.\build.ps1
```

使用 CMake、Ninja、MinGW-w64 GCC 16.2.0 和 C++20。构建脚本运行独立测试，静态链接 C++ 运行库，读取 `CMakeLists.txt` 的项目版本，输出 `dist\OwnVPN-<版本号>.exe`，例如 `dist\OwnVPN-0.3.6.exe`。后续发布统一使用带版本号的文件名。不需要把 GCC 的 DLL 复制到客户端目录。

已导入配置后，可运行只读的官方核心管理接口探测：

```powershell
.\build\ownvpn_tests.exe --probe
```

探测使用 HOLD，不提交真实账户、不释放连接、不创建 VPN 网卡、不改变系统路由。单元/协议测试通过不能代替真实公司 VPN 登录验证。

## 模块设计

| 模块 | 职责 |
| --- | --- |
| `main.cpp` | 原生 Win32 界面、输入和状态呈现 |
| `usage_panel.*` | 可展开的使用说明、原生超链接及滚动布局 |
| `system_tray.*` | 托盘注册、状态颜色、连接菜单及 Explorer 重启后恢复图标 |
| `connection_controller.*` | 主界面侧连接生命周期、会话内 UAC helper 复用、IPC 事件转发 |
| `reconnect_policy.*` | 独立的重连等待、退避、稳定连接恢复和取消策略 |
| `clipboard.*` | Unicode 剪贴板写入、Windows 内存所有权和失败清理 |
| `engine.*` | 官方 OpenVPN 进程、管理连接、正常退出、失败回收 |
| `protocol.*` | 独立管理协议状态机、凭据转义与验证码打包 |
| `management_startup.*` | 管理接口认证、状态订阅、主动放行和启动进度跟踪 |
| `management_commands.*` | 管理命令顺序确认、认证命令有效期和未发送凭据清理 |
| `otp_provider.h` | `IOtpProvider` 扩展点与手动验证码实现 |
| `totp.*` | RFC 6238 生成、Base32/绑定链接解析、可取消的取码与时间接口 |
| `totp_store.*` | 按配置和用户名隔离的加密绑定、模式与使用周期记录 |
| `totp_detection.*` | 两轮本机验证码参数匹配，不保留输入验证码 |
| `qr_import.*` | 本机 WIC 图片读取和 ZXing QR 解码 |
| `otp_setup_dialog.*` | 独立的绑定设置窗口 |
| `profile.*` | 配置导入、依赖复制、兼容转换、参数验证和分流策略 |
| `credential_store.*` | 按配置隔离的 Windows 凭据存储 |
| `ipc.*` | 有界、长度前缀的连接请求及事件编解码 |
| `settings.*` | 不含密码和验证码的用户设置 |
| `core.*` | Unicode、文件、随机数、受限目录及 Windows 句柄基础设施 |
| `tests/tests.cpp` | 协议、配置、凭据隔离、IPC 和可选真实核心探测 |

自动验证码模块实现 `IOtpProvider::GetCode(const OtpRequest&, std::stop_token)`，返回验证码及真实过期时间。工作进程的组装点按模式选用 `ManualOtpProvider` 或 `TotpOtpProvider`。该接口不能直接调用界面控件。TOTP 的时钟、等待、密钥加载和使用周期存储可注入，便于独立测试和替换。

TOTP 流程按 RFC 6238 实现，底层 HMAC/SHA 使用 Windows CNG（BCrypt），没有自行实现密码学哈希。测试包含 RFC 附录 B 全部 18 组 SHA1/SHA256/SHA512 向量，以及 6 位补零、周期切换、过期等待、取消、重复连接、账号隔离和本机图片解码。`tests/fixtures` 只含公开测试密钥对应的合成二维码，与公司账号无关。

二维码依赖固定为 ZXing-C++ 3.1.1，首次构建下载约 1 MiB 上游源码并校验 SHA-256；后续构建可离线使用缓存。发行包静态链接读取器，并附依赖许可证、声明及完整上游源码归档。

0.2.1 修复认证等待期间点击断开可能卡住的问题：取消信号使用独立的 Windows 事件，界面线程不再同步写入管道；后台监视退出和超时。诊断区启动时不创建，点击后才展开，并按实际窗口 DPI 调整尺寸。验证码定时器只刷新数字和倒计时，主界面采用双缓冲，避免整窗闪烁。

0.2.2 增加“显示密码”、移除“记住验证码”及其存储，清理旧手动验证码；预览每 100ms 检查时间边界，仅当数字或倒计时改变时刷新，减少原 1 秒定时器产生的显示延迟。新增两轮本机参数核对，并修复保留现有密钥时算法/周期修改未保存的问题。

界面通过事件接收状态，协议不依赖窗口/网络；凭据按配置隔离存入 Windows 凭据管理器。生产使用的日志只输出已知状态及固定错误类别，避免保存账号、密码、验证码、私钥或服务器返回的任意文本。

## 数据及权限边界

源码目录不包含公司证书、私钥、服务器地址或真实凭据。个人配置保存在本机 LocalAppData，不随源码和程序打包。目录 ACL 限制为本用户、SYSTEM 和管理员；密码与 TOTP 绑定密钥由 Windows 凭据管理器保存，单次验证码不持久化，均不写入设置文件、命令行或临时明文凭据文件。

连接进程通过仅限本机的随机命名管道通信，双向核对进程 ID。官方核心通过环回地址反向连接界面服务，校验连接进程身份并使用随机管理口令；管理口令从继承的匿名管道交给 OpenVPN。正常停止使用官方 Windows 退出事件，子进程采用显式句柄继承列表和 Job Object 回收。

主界面和后台连接进程需在同一 Windows 用户下运行；UAC 如要求输入另一个管理员账户，可能无法读取当前用户的配置。首版没有安装常驻系统服务。异常强制结束/系统断电后应检查网卡、DNS 和路由恢复情况。

使用已安装的官方核心，发行包不重分发 OpenVPN 及其驱动；若后续将官方组件一起打包，需要保留相应许可证和分发声明。
