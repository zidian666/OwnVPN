# 版本管理

当前源码从 0.3.9 建立 Git 基线；此前的程序版本没有完整的源码快照，不补造历史提交。

主分支为 `main`。后续功能修改和修复均保留提交记录，发布时使用 `v<版本号>` 标签标记对应源码。版本号须同步更新 `CMakeLists.txt`、`resources/app.rc` 和 `resources/app.manifest`。

发布前运行 `build.ps1`，完成编译和测试。程序输出为 `dist/OwnVPN-<版本号>.exe`，发布记录写入 README。构建产物不提交到源码仓库。

仓库保持私有。公司 VPN 配置、证书、私钥、账号密码、个人二维码、TOTP 密钥、运行日志和本机设置不提交到 Git。测试使用的公开 RFC 示例和合成数据除外。
